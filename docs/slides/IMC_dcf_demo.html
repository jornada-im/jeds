dataset-citation-finder

Finding the papers that cite EDI datasets

Gregory Maurer

2026-10-18

How do we know when people use data?

Data citations!

  • Citation data is scattered across several scholarly databases
  • No single source has every citation
  • dataset-citation-finder queries several sources and merges the results, recording which source reported each citation

Some history

  • EDI repository has a dataset citation database
  • You can upload your own dataset citations to EDI
  • EDI staff used to monitor for and add Google Scholar citations, but no longer

EDI is looking for ways to do this automagically…

Citation databases

  1. DataCite events - indexes citations of DataCite DOIs (including EDI’s)
  2. OpenAlex - an open scholarly publication/citation graph
  3. OpenCitations - open registry of scholarly citations

Numbers 2 & 3 pull data from multiple sources, including Crossref, PubMed, OpenAIRE, and more…

Demo for today

First a basic example with 2 DOIs, then a more complex example:

  1. List every DOI in one EDI scope (knb-lter-nes)
  2. Search DataCite Events and OpenAlex for papers citing them
  3. Explore the merged results
  4. Export to CSV

Step 1 · List the scope’s DOIs

EDI DOIs all look like 10.6073/pasta/<hash>, so the DOI doesn’t say which scope it’s in.

DataCite does store each record’s PASTA URL, so fetch_scope_dois.py uses that:

python demo/fetch_scope_dois.py knb-lter-nes
71 DOIs written to knb-lter-nes_dois.txt

Citation databases list citations per DOI, so we need every EDI package revision to be listed. 71 is the revision count.

Step 2 · Find citations

from dataset_citation_finder import find_citations

dois = open("knb-lter-nes_dois.txt").read().split()

cited = find_citations(
    dois, db_path="nes_demo.sqlite",
    sources=["datacite_events", "openalex", "opencitations"],
    email="gmaurer@nmsu.edu",
    # api_keys={"openalex": "..."},   # optional, raises rate limit
)

Uncited datasets

Not everything gets cited, but we should make sure whether a database answered first.

queried = read_citations("nes_demo.sqlite", table="queried")   # read in the 'queried' table
answered = set(queried.dropna(subset=["queried_at"])["cited_doi"]) # drop any not found in a database

uncited = answered - set(cited["cited_doi"])
len(uncited)
42 # DOIs in the scope that have never been cited

Step 4 · Export

This is how to export the citations (58 rows, 1 for each cited dataset)

cited.to_csv("nes_citations.csv", index=False)

read_citations("nes_demo.sqlite", raw=True) gives one row per source instead (96 rows), with first/last seen dates.

The database is re-freshable

  from dataset_citation_finder import find_citations, read_citations

  db = "nes_demo.sqlite"

  # 1. Get your DOI list and the time of the last check from the store.
  queried = read_citations(db, table="queried")
  dois = queried["cited_doi"].unique().tolist()
  last_run = queried["queried_at"].max() 

  # 2. Re-check every DOI against every source.
  df = find_citations(dois, db_path=db, email="you@example.org")

  # 3. Citations found for the first time in this run.
  new = df[df["first_seen"] > last_run]
  len(new)

This updates the database in place, and you can pass refresh_after=timedelta(days=30) to only check DOIs that haven’t been checked for a month or more.

Scaling up

This small scope takes a few minutes, but we can improve performance a bit with API keys.

Scope DOIs
knb-lter-nes 71
knb-lter-ble 132
knb-lter-kbs 188
knb-lter-cap 510
knb-lter-sev 626

Theoretically we can do all of EDI, but it is ~83k DOIs, so will probably need to run on a server.

OpenAlex dominates runtime (about 2 requests per DOI, throttled). With an API key, a large sweep can still hit the daily cap; re-run the next day with refresh_after and it picks up where it stopped.

Summary

  • Works with one DOI or an arbitrary list (like a whole EDI scope)
  • Sources so far: DataCite Events, OpenAlex, OpenCitations
  • Records which source reported each citation
  • Results go into a SQLite store you can resume, then export to CSV
